# Low Level Design (LLD) Learning Path

A comprehensive repository to learn Low Level Design from beginner to expert level using **TypeScript/JavaScript**.

- [ ] [OOP Concepts](./01-fundamentals/01-oop-concepts/README.md)
  - Classes & Objects
  - Inheritance
  - Polymorphism
  - Encapsulation
  - Abstraction
- [ ] [SOLID Principles](./01-fundamentals/02-solid-principles/README.md)
  - Single Responsibility Principle (SRP)
  - Open/Closed Principle (OCP)
  - Liskov Substitution Principle (LSP)
  - Interface Segregation Principle (ISP)
  - Dependency Inversion Principle (DIP)
- [ ] [Other Principles](./01-fundamentals/03-other-principles/README.md)
  - DRY (Don't Repeat Yourself)
  - KISS (Keep It Simple, Stupid)
  - YAGNI (You Aren't Gonna Need It)
  - Composition over Inheritance

1. **README.md** - Concept explanation with notes
2. **example.ts** - Code implementation
3. **interview-questions.md** - Common interview questions & answers

## How to Use This Repository

1. Follow the roadmap in order (Phase 1 → Phase 4)
2. Read the notes first to understand the concept
3. Study the code implementation
4. Practice with interview questions
5. Mark topics as completed in this README

## Setup

```bash
# Install TypeScript globally
npm install -g typescript ts-node

# Run any TypeScript file
ts-node path/to/file.ts
```
